# JavaScript Exploration & Learning Notes

A repository dedicated to documenting my learning journey, practice code, and exploration of JavaScript concepts.

## 📁 What's Inside

- **Event DOM on Form**
> Implementation and examples of various DOM events on HTML forms, such as `onInput`, `onFocus`, `onSubmit`, `onChange`, and more.
- **Web Storage**
> Example usage of web storage (both local and session storage) like how to get, set and modify it

## 🚀 How to Run

1. Clone or download this repository. 
2. Open any `.html` file directly in your preferred web browser. Each Folder will have specific topic.
